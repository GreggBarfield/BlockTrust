Tag Data Smart Upload

This module allows you to upload your tag numbers, plus any associated data simply by dropping your file into ‘the bucket’. Our system will help you clean it up, if necessary, then put it in the proper place in our system so you can track your animals up and down the beef supply chain.

Currently we are accepting the following data fields automatically:

  • Member Number or affiliate ID (Required)
  • Electronic Tag Number (15 digit EID associated with the tag) (Required)
  • Visual Tag Number
  • Date of Birth
  • Birth Weight
  • Breed
See Complete List
  • Calf Registration Number
  • Sire Registration Number
  • Dam Registration Number
  • Weaning Date (Required if you want to upload wean weight or creep feed)
  • Wean Weight
  • Creep Feed
  • Sex
  • Implants

If there are other data points you want to add, please Contact Us

To begin, you must have your data in a data file (Excel Spreadsheet or Comma Delimited file). Field names must be at the top of each column. Remember where you have it stored on your computer.

Push the button below and follow the instructions. You will receive a confirmation email once the data is loaded (should be immediately).
